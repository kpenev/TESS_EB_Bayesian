\fancysection{Work Plan}
%
\label{sec:work_plan}

Based on the preliminary development carried out in preparation for this
proposal, we estimate the timeline for this project shown below. In parenthesis
we show the expected fractional contribution to each task by the graduate
student (labeled GS) and by the PI (labeled PI).

\begin{description}
%
    \item[by month 2:] Implement EB parameters LC model including maximum
        likelihood fit (GS:~80\%, PI:~20\%).
%
    \item[by month 5:] Implement EB parameters SED model (GS:~80\%, PI:~20\%).
%
    \item[by month 6:] Implement MCMC sampling for stamp-based LCs (GS:~70\%,
        PI:~30\%).
%
    \item[by month 8:] Begin stamp-based MCMC sampling on HPC and implement FFI
        LC detrending\\(GS:~70\%, PI:~30\%).
%
    \item[by month 10:] Complete stamp-based sampling on HPC. Prepare and submit
        stamp-based EB parameter article (GS:~60\%, PI:~40\%).
%
    \item[by month 11:] Implement FFI-based MCMC sampling and begin running on
        HPC (GS:~70\%,\\PI:~30\%).
%
    \item[by month 12:] Implement ACF and WT (LSP is already implemented in
        astropy \citep{astropy_lomb_scargle}) (GS:~80\%, PI:~20\%). FFI MCMC
        sampling is on-going.
%
    \item[by month 15:] Implement automated selection of stamp-based spin
        analysis targets and tune by comparing to \citep{CantoMartins_et_al_20},
        \citep{Oelkers_et_al_18}, and \citep{Lurie_et_al_17} (GS:~70\%, PI:
        30\%). FFI MCMC sampling and manual review is on-going (GS:~70\%, PI:
        30\%).
%
    \item[by month 17:] Complete FFI MCMC sampling, continue manual review.
        Start automated selection of stamp-based spin targets on HPC. Begin work
        on EB physical parameters from FFI article (GS:~60\%, PI:~40\%).
%
    \item[by month 19:] Submit EB physical parameters from FFI article (GS:
        60\%, PI:~40\%). Tune and start automated selection of spin targets for
        FFI LCs (GS:~70\%, PI:~30\%).
%
    \item[by month 21:] Complete manual review and submit article with
        stamp-based spin measurements (GS:~60\%, PI:~40\%).
%
    \item[by month 24:] Complete manual review and submit article with FFI-based
        spin measurements (GS:~60\%, PI:~40\%).
%
\end{description}
